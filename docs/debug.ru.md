# Отладка в кооперативе RayLink

[English](debug.md)

Отладка устроена как `sv_cheats 1` в CS: её включает сервер (хост), и тогда меню отладки получают все игроки. Любое действие из меню выполняет сервер, поэтому мир у всех остаётся одинаковым.

**Нужна сборка с отладкой:** сейчас это канал **Dev**, сборка 41.1 и новее. Вся группа должна быть на одной сборке.

## Как включить

Включить отладку может только хост (или окно выделенного сервера). Обычные игроки включить её не могут.

| Способ | Что сделать |
|---|---|
| Галочка в лаунчере | Настройки → «Отладка при хостинге» (лаунчер 0.3.23 и новее). Когда вы хостите игру через лобби, она стартует с включённой отладкой. |
| Ключ запуска | Запустить игру хоста с ключом `-dbg`. |
| Консоль хоста | Открыть консоль (`~`) и ввести `coop_debug on`. Выключить — `coop_debug off`. Узнать состояние — `coop_debug`. |
| Выделенный сервер | Ввести `coop_debug on` в окне сервера. |
| Окно F7 у хоста | В шапке окна отладки у хоста есть кнопка «Вкл / Выкл» — это та же команда. |

Если хост хостит кнопкой в самой игре, без лобби, лаунчер ключ не добавит — включите командой `coop_debug on`.

Включённая отладка помечает сохранение мира как сделанное с отладкой, как в обычной Anomaly.

## Меню F7

Нажмите **F7** в кооп-игре. У всех игроков, у хоста тоже, справа от прицела открывается стеклянная панель: игра, прицел и цель
остаются видны, курсор свободен, ходить можно дальше (это настройка).

- **Двигать** — за заголовок, **размер** — за любой край или угол (не меньше 640 x 420); всё внутри перестраивается само, на
  4:3, 16:10, 16:9 и 21:9. С экрана окно не уходит.
- **Вид** (справа вверху): прозрачность 60-100 %, размытие под панелью (слабое / среднее / сильное; на рендерах DX9 R2, DX10 и
  DX11, на статическом освещении — только тонированное стекло), плотность (плотно / обычно / крупно), ходьба с открытым окном,
  вопросы перед разрушительным, сброс места и размера. Хранится только на этом компьютере (`axr_options.ltx`, секция
  `[coop_debug_ui]`), вместе с последней страницей, фильтрами и избранным.
- **Отладка выключена** — видны только «Обзор» и «Справка»: можно смотреть, ничего нельзя менять.
- **Отладка включена** — открываются все страницы. У хоста (или владельца выделенного сервера) в заголовке кнопка «Включить / Выключить».

| Страница | Что там |
|---|---|
| Обзор | Карточки: цель под прицелом (имя, id, группировка, ранг, отношение к вам, отряд, смарт) и её вещи; ваша позиция (уровень, координаты, вершины) и «записать»; ближайший объект; игроки (ник, уровень, жив или ранен, пинг); время, скорость времени, погода, выброс и пси-шторм. Кнопки «Видит ли меня?» и «Данные сервера». |
| Предметы | Все предметы, которые можно создать, уже в списке с иконками из инвентаря: Все, Избранное, Оружие, Патроны, Броня, Артефакты, Медицина и еда, Обвесы, Прочее. Поиск по имени или секции (несколько слов, по-русски тоже), сортировка А-Я или по секции. Выбрали строку — количество (1 / 2 / 5 / 10 / 20), куда (в рюкзак / в прицел / рядом), «Создать». |
| NPC | Отряды сталкеров, отряды мутантов, сталкеры, мутанты, аномалии, объекты; появляются в прицеле или рядом. |
| Уровни | Все уровни по названиям; «Перейти на уровень» (решают правила переходов сервера, сюжетные — вместе). |
| Избранное | Отмеченное в «Предметах», «NPC» и «Уровнях» (кнопка «В избранное» справа). |
| Цель | Для объекта под прицелом: убить, ранить, обновить товар торговца, удалить, очистить инвентарь; отношение к вам; репутация себе или его отряду; группировка его отряда (выбор из списка); сделать его отряд напарниками. |
| Я | Бессмертие, бесконечные патроны, невидимость для ИИ; деньги +10 тыс. / +100 тыс. / +1 млн; телепорт в точку прицела или к любому игроку; базовый набор, тестовый отряд. |
| Мир | +1 / 3 / 6 / 12 часов, поставить час, скорость времени x1-x50, 6 видов погоды, выброс и пси-шторм, респауны вкл/выкл, удалить обычные отряды, открыть маршруты, статьи и записи, выдать или забрать инфопоршень. |
| Справка | Что есть на каждой странице, как устроено окно, синтаксис консоли. |

Внизу — лента ответов сервера со временем: зелёное сделано, янтарное ждёт, красное отказано; последний отказ показан целиком,
с причиной от сервера. Опасные действия (удалить, очистить инвентарь, удалить отряды, инфопоршни) сначала спрашивают
(если это не выключено во «Виде»).

## Кто что получает

| Действие | Где выполняется | Кого касается |
|---|---|---|
| Время, погода, выброс, пси-шторм, респауны, маршруты, статьи, инфопоршни, удаление отрядов | сервер | весь мир, все игроки |
| Деньги, предметы в инвентарь, базовый набор, телепорт, смена уровня | сервер | только тот, кто попросил |
| Бессмертие, бесконечные патроны, невидимость для ИИ | сервер | только тот, кто включил |
| Спавн предметов, NPC, монстров, аномалий, тестового отряда | сервер, в точке, которую выбрал игрок | все их видят |
| Действия с целью (убить, удалить, отношения и т. д.) | сервер или сервер карты цели | все |

Каждое изменение мира объявляется в чате: кто и что сделал.

## Консоль сервера

На хосте и на выделенном сервере работают команды:

```
coop_dbg <команда> [@игрок] [ключ=значение ...]
coop_dbg help
coop_dbg help <команда>
```

`@игрок` — ник (`@Вася`) или номер (`@2`). Без `@игрок` команда выполняется для оператора. Все команды, кроме `help`, работают только при включённой отладке.

Примеры:

```
coop_dbg spawn_item @Вася sec=wpn_ak74 n=1 at=inv
coop_dbg spawn_object @Вася sec=<секция NPC или монстра> at=near
coop_dbg money @Вася a=50000
coop_dbg god @Вася on=1
coop_dbg tp_to_player @Вася p=@Петя
coop_dbg time_add h=6
coop_dbg time_to h=12 m=0
coop_dbg weather w=<погода>
coop_dbg surge on=1
```

| Команда | Аргументы | Что делает |
|---|---|---|
| `time_add` | `d= h= m=` | сдвинуть время вперёд |
| `time_to` | `h= [m=]` | вперёд до этого часа |
| `time_factor` | `f=` | скорость игрового времени |
| `weather` | `w=` | погода |
| `surge`, `psi` | `on=1/0` | выброс, пси-шторм |
| `respawns` | `on=1/0` | респауны смартов |
| `unlock_routes` | — | открыть все маршруты |
| `unlock_ency` | `what=articles/notes` | открыть статьи или записи |
| `release_common_squads` | — | удалить обычные отряды |
| `info` | `k=give/take i=` | выдать или забрать инфопоршень мира |
| `god`, `ammo`, `invis` | `on=1/0` | бессмертие, бесконечные патроны, невидимость для ИИ |
| `money` | `a=` | деньги (до ±1 000 000 за раз) |
| `basic_kit` | — | 15 базовых предметов |
| `tp` | `x= y= z=` | телепорт на своём уровне |
| `tp_to_player` | `p=` | телепорт к игроку |
| `level` | `name=` | смена уровня |
| `spawn_item` | `sec= [n=1..20] [at=inv/point/near]` | предметы |
| `spawn_object` | `sec= [at=point/near/smart] [sm=]` | NPC, отряд, техника, аномалия |
| `test_squad` | `[n=3]` | отряд своей группировки в ближайшем смарте |
| `kill`, `wound`, `release`, `inv_clear`, `trade_refresh`, `companion` | `t=<id>` | действия с объектом |
| `relation` | `t= [t2=] r=friend/neutral/enemy` | отношение |
| `goodwill`, `squad_goodwill` | `t= [t2=] g=-5000..5000` | репутация |
| `faction` | `t= c=` | группировка отряда |
| `obj_info`, `can_see` | `t=` | что знает сервер; видит ли NPC игрока |
| `lua` | `<код>` | выполнить Lua на сервере (только консоль сервера) |

## Если не работает

| Ответ | Что значит |
|---|---|
| `debug is off` | Отладка на сервере выключена — пусть хост введёт `coop_debug on`. |
| `rate limited` | Слишком часто. Подождите секунду. |
| `too_far` | Точка спавна дальше 200 м от вас. |
| `other_level` | Цель на другой карте. |
| `no_player` | Нет игрока с таким ником или номером. |
| `not in the world` | Вы ещё не вошли в мир. |

В одиночной игре F7 открывает обычное меню отладки Anomaly, как раньше.
