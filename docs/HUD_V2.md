# HUD v2 — компас, команда, пинг (спецификация)

Решение владельца 2026-10-23: «делай компас как решил ты». Зрительный образ — `docs/hud/hud_v2_mockup.png` и
`docs/hud/hud_v2_mockup_detail.png`, кадр GAMMA, Bahnschrift вместо игрового `letterica16`. Это эталон: в игре
должно выглядеть так же по раскладке, цветам и плотности.

## Зачем

Нынешняя панель группы справа («26 м, player_a ★» поверх стокового слота компаньона) владельцу не нравится. В GAMMA
есть Tactical Compass (`420- Tactical Compass - explorerbee`, в профиле выключен). Он видит только метки КПК известных
ему типов, поэтому наших союзников не показывает. Метки союзников, их состояния, задания, смерти и привалы знает только
кооп, поэтому это фишка ядра.

## Архитектура: данные в ядре, оформление своё, но заменяемое

- **Данные** — `gamedata\scripts\coop_hud_markers.script`, модуль Core, один на машине. Собирает метки из источников
  и отдаёт список. Публичный API для модов:
  - `coop_hud_markers.list()` → массив меток `{ key, kind, pos (vector), color {r,g,b}, label, state, priority }`;
  - `coop_hud_markers.add_source(name, fn)` — мод добавляет свой источник (`fn()` → массив меток).
  Расстояние и направление считает потребитель от своей камеры.
- **Оформление по умолчанию** — Core, Lua + XML + текстуры, не C++. Стиль правится без пересборки exe, мод может
  заменить его своим:
  - `coop_hud_compass.script` + `configs\ui\ui_coop_compass.xml` (+ `_16`);
  - панель команды — переписанная `UICoopParty` в `coop_core_hud.script`.
- **Выключатель** в опциях игрока (страница «Кооператив», домен игрока, не хоста): компас вкл/выкл, панель вкл/выкл.
- **Переходник для Tactical Compass**: если он установлен и наш компас выключен, союзники и пинги подаются в него через
  `tc_markers.add(id, spot, "companion")`; его иконки, без наших цветов.
- Движок не трогать без нужды. Если чего-то не хватает в Lua API (например, `game.world2ui` нет в нашем exe) — сначала
  проверь, обоснуй в отчёте, и только потом добавляй минимальный экспорт.

## Компас (верх по центру)

- **Размер — меньше (владелец: «чуть поменьше»):** ширина 38 % экрана, высота полосы 24 px при опорных 1024×768,
  отступ сверху 20 px; буквы 11 px, подписи 10 px, иконки меток 10–12 px. Над полосой — курс в градусах
  (например «247°») и треугольник-засечка по центру.
- **Шкала белая, как на референсе владельца** (правка 2026-10-23: «белого побольше, а не жёлтого; метки — по цветам»).
  Фон — тёмный (#0C0D0A) с альфой ~0,33 (владелец: «чуть менее мутное сзади»), к краям гаснет на последних 16 % ширины. Через полосу — тонкая белая линия
  (#F4F5F6, альфа ~0,8, то же угасание). Буквы — над линией, деления — вниз от неё.
- Деления: каждые 5° (2 px), 15° (4 px), 45° (5 px) и буквы N NE E SE S SW W NW — всё белое #F4F5F6 с тенью 1 px.
  Засечка по центру — белый треугольник под линией, курс над полосой — белым. Жёлтого и песочного в шкале нет.
  Поле зрения полосы — 160° (опция: 120 / 160 / 200).
- Метки на полосе — иконки 12–14 px с 1 px тёмной обводкой, плоская заливка, **без свечения**:
  - **союзник** — шеврон вниз цветом игрока (палитра `[coop_player_colors]` в `mod_system_coop.ltx`). Под полосой —
    расстояние; ник, только когда союзник в ±10° от центра;
  - **союзник ранен** — красное кольцо с крестом (`down` из палитры), пульс 1 Гц;
  - **союзник мёртв, эвакуирован или наблюдатель** — серый (`dead`);
  - **активное задание** — заполненный ромб #E8C25A и расстояние под полосой;
  - **другие задания** — полый ромб, альфа ~0,6;
  - **метка смерти и мешочек** — череп или рюкзак, приглушённо-красный;
  - **свой привал** — палатка или костёр, шалфей #92BE9A;
  - **пинг** — голубая точка #78E1EB в кольце цвета автора, живёт 20 с, появляется с пульсом 300 мс.
- Метки за пределами поля зрения прижимаются к краю полосы со стрелкой ◀/▶ и альфой ~0,7.
- Разница по высоте больше 5 м — маленький ▲/▼ у расстояния.
- Движение плавное: позиции интерполируются по кадрам, появление и исчезновение — 150 мс.
- Метки не перекрывают друг друга подписями. При тесноте приоритет: пинг > ранен > союзник > активное задание >
  остальное. Подписи низших приоритетов скрываются.

## Производительность и надёжность

- Метки собираются 10 раз в секунду, позиции на полосе обновляются каждый кадр. Пулы статиков, без создания окон в
  кадре.
- Время на кадр — до 0,3 мс при 8 союзниках и 20 метках (проверить счётчиком в `coop_status`).
- Ошибка источника метки (мод) ловится `pcall`, считается и не ломает HUD.
- Вне сессии (одиночная игра) — компас работает: задания, привалы, пинг выключен. Панель команды скрыта.

### Почему компас был почти пустой
- **У клиента** `task_manager.task_info` — заглушки `coop_tasks` (`stage / status`), без `t` и `current_target`: источник
  `tasks` пропускал все задания. Теперь задача берётся из движка (`db.actor:get_task(id, true)`), цель — `current_target`,
  если она на этом уровне, иначе объект метки КПК задачи (`CGameTask:get_map_object_id()`, метка реплицируется
  клиентам). Нет ни того, ни другого — задание не показывается.
- **Меток КПК не было совсем** (торговцы, тайники, переходы, метки PAW): в v2 их источника не существовало.
- Своя метка Personal Adjustable Waypoint — это задача `task_placeable_waypoint` с целью-`script_zone`: раньше шла
  ромбом задания (у клиента не шла вовсе), теперь — отдельный вид «своя метка».

### Источник правды для задания
`current_target` на этом уровне → иначе метка КПК задачи. `current_target` хост обновляет сам (task_objects) — он
свежее; метка — это ровно то, что игрок видит на карте КПК, и единственная цель, которая есть у клиента. Обе на других
уровнях — задание не показывается («задания без цели не показывай»).

### Метки КПК (источник `pda`, `coop_hud_markers.script`)
Состав — как у Tactical Compass по умолчанию (`tc_defs.spot_categories`, группы, включённые в его MCM):

| Вид | Типы меток | Значок (атлас) | Цвет | Предел |
|---|---|---|---|---|
| `npc` trader / mechanic / medic | `ui_pda2_trader/mechanic/medic_location` | монеты / ключ / плюс в квадрате | #E6E1D0 | 60 м |
| `npc` прочие | barman, special, scout, quest_npc, companion | силуэт | #E6E1D0 | 60 м |
| `stash` normal / unique / player / searched | `treasure`, `treasure_all` / `_unique` / `_player` / `_searched` | ящик | #D7CDB4 / #B99AE0 / #7FB2E5 / #8F8A7E ×0,6 | 100 м |
| `sleep` | `ui_pda2_actor_sleep_location` | полумесяц | #92BE9A | 50 м |
| `transition` | `level_changer_*` (8 направлений) | ворота со стрелкой, ×0,85, приоритет 5 | #B8C4CC | 300 м |
| `pin` (метки PAW) | `paw_*`, кроме `paw_ping*`, `paw_task_default` | флажок; свой цвет пина PAW, если задан | #D6DEE4 | 500 м |
| `waypoint` (своя метка PAW) | задача `task_placeable_waypoint` | булавка, подпись всегда, приоритет 22 | #F4F5F6 | без предела |

Не показываются: отряды варфейра, трупы, костры, насосы (у TC выключены по умолчанию), метки заданий (идут из
`tasks`), метки смерти (из `deaths`), наши локальные `coop_*`. На объекте несколько меток — одна, самая говорящая
(pin > stash > npc > sleep > transition). Подпись — хинт метки КПК без `%c[…]` и второй строки; id строки переводится,
непереведённый id подписью не становится.

**Как перечисляются (как у TC):** `level.map_get_object_spots_by_id(id)` по всем id 1…65534 — быстрый проход после
загрузки (`pda_scan_first` = 2048 id за кадр, ~32 кадра), дальше бесконечный медленный (`pda_scan_frame` = 96 id за
кадр, круг ~11 с при 60 fps). Пины PAW — сразу из `tasks_placeable_waypoints.pins` (имя, свой цвет). Колбэк актора
`map_location_added` — один слот на всех; Tactical Compass забирает его и пересылает в axr-колбэк
`actor_map_location_added` — если TC стоит, слушаем там (метка появляется сразу), сами слот **не занимаем**. Удалённая
метка уходит при следующем опросе источника (раз в 500 мс, `level.map_has_object_spot`). Позиции неподвижных видов
кэшируются на 5 с, объект на другом уровне переспрашивается через 5 с. Стоимость прохода видна в `coop_status`
(часть `pda sweep` строки `hud v2: frame`).

### Затухание по дальности (`coop_hud_compass.fade_of`, `range_of`)
- Полная альфа до `fade_near_pct` = 25 % предела вида; дальше smoothstep до `fade_far_alpha` = 0,35 и размер значка до
  `fade_far_scale` = 0,8 на пределе; дальше предела — не показывать (исчезает за те же 150 мс).
- Без предела (`range_* = 0`: союзники, пинги, своя метка, активное задание) — та же кривая против `fade_ref_m` = 300 м,
  дальше — 0,35, никогда не скрывается.
- Пределы по видам: `range_ally/ping/waypoint/task_active = 0`, `range_task = 400`, `range_death = 400`,
  `range_camp = 300`, `range_pin = 500`, `range_stash = 100`, `range_npc = 60`, `range_sleep = 50`,
  `range_transition = 300`, `range_default = 300` (вид мода без строки). Своё поле `range` у метки мода важнее.
- Совмещение: прижатые к краю — ещё ×0,7, и прижимаются **только** приоритеты ≥ 20 (пинг, ранен, союзник, своя метка,
  активное задание); остальное за полем зрения не показывается — края не забиваются тайниками. Метка далеко за
  пределом (×1,05) или вне поля (+10°) слот не занимает; при тесноте (24 слота) остаются ближние. Подписи затемнённых
  меток не тусклее 0,6.
- Всё — строками `[coop_hud_layout]` (`mod_system_coop.ltx`), значения по умолчанию — `coop_hud_layout.script`.
