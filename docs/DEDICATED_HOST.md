# Выделенный хост: сервер мира без окна игры и без игрока (2026-11-01)

План: `docs/plans/2026-10-24-f3a-split-levels.md` §12. Раздельные карты: `docs/SPLIT_LEVELS.md` §7a. Безоконный режим: `engine/HEADLESS_AUDIT.md`.
Проверка в игре: `docs/checks/2026-11-01-dedicated-host.md`.

## Что это

Обычный хост это окно игры с игроком внутри. Выделенный хост это тот же exe с ключом `-coop_dedicated`: нет окна игры, нет игрока, есть настоящая консоль Windows.
Все игроки, включая владельца этого ПК, входят обычными клиентами.

Модель одной фразой: **хост, чей игрок навсегда стоит на служебной карте `fake_start` и ничего не делает.** Поэтому новых механизмов почти нет:

| Что | Как получается |
|---|---|
| Запуск без окна | тот же безоконный режим, что у сервера карты: WARP, без звука, без мьютекса (`g_coop_headless`) |
| Роли | `dedicated_roles()`: `WorldServer`, `MapAuthority`, без `Player` |
| Актёр | призрак, как у Mk: `mapserver::ghost_frame`, `ghost_actor()`. Ставится на `fake_start` в `on_alife_objects_loaded` |
| Карты | раздельные карты включены всегда (`game_split()`). Место хоста не играет (`Seat::plays = false`), поэтому карта с игроками всегда получает Mk |
| Сеть | те же порт и протокол. Для игроков хост просто стоит на другой карте |

## Запуск

```
AnomalyCoopDX11AVX.exe -fsltx fsgame_server.ltx -coop_dedicated [порт] -coop_new
AnomalyCoopDX11AVX.exe -fsltx fsgame_server.ltx -coop_dedicated [порт] -coop_load last
AnomalyCoopDX11AVX.exe -fsltx fsgame_server.ltx -coop_dedicated [порт] -coop_load "имя сейва"
```

- Порт по умолчанию 27960.
- `-coop_new` создаёт мир. `-coop_load last` берёт самый свежий сейв папки, `-coop_load <имя>` указанный.
- Без `-coop_new` и `-coop_load` окно ждёт команду `coop_world`.
- Свой `fsgame` обязателен: у сервера своя папка данных, иначе он делит сейвы и лог с игроком этого ПК. Лаунчер пишет `fsgame_server.ltx` сам. Mk получают `fsgame_ms<k>.ltx` из него.
- `-coop_hidden` (2026-11-12): окна консоли нет совсем. Ввод читается только из канала, который дал лаунчер. Конец канала значит, что лаунчер или игра хоста закрылись: сервер сохраняет мир и выходит. Строки в окно не пишутся, всё остаётся в логе.

### Сессия поднимается сама (2026-11-12)

Раньше автозапуск пробовал поднять сессию один раз. Если мир в этот кадр был не готов или порт занят, сервер оставался без сессии. Теперь он пробует каждый кадр, пока мир не готов, а после отказа повторяет через 5 с, потом реже, до 30 с.

| Строка лога | Что значит |
|---|---|
| `[coop] dedicated: waiting for the world (<причина>): level … g_actor … alive …` | мир ещё не готов; пишется один раз на каждую новую причину |
| `[coop] dedicated: the session is up on port P, N s after the level came` | сессия поднята |
| `! [coop] dedicated: gave up waiting for the world after N s: <причина>` | прошло 15 минут с появления уровня; дальше только `coop_host <порт>` руками |

Без `-coop_new` и `-coop_load` часы не идут: сервер ждёт `coop_world` сколько угодно.

## Консоль

Настоящее окно Windows (`AllocConsole`): правка строки и история стрелками работают сами. Лог старта виден с первой строки. Заголовок показывает порт, игроков и серверы карт.

| Строка | Что делает |
|---|---|
| `coop_players` | список: номер, ник, карта, пинг, потери, состояние |
| `coop_kick <номер\|ник> [причина]` | выкинуть игрока, персонаж остаётся в мире |
| `coop_autosave_now` | автосейв на ближайшем безопасном кадре |
| `coop_restore` | список автосейвов, свежий первым |
| `coop_restore <номер\|имя>` | мир откатывается, все игроки перезагружаются в него |
| `coop_time` | игровое время и множитель |
| `coop_time <чч[:мм]>` | мир идёт вперёд до этого часа, назад часы не ходят |
| `coop_status` | полная сводка сессии |
| `coop_world new\|last\|<сейв>\|list` | выбрать мир, пока его нет; `list` работает всегда |
| `coop_console_log 0\|1\|2` | что из лога показывать: ошибки, сессия, всё |
| `/go` | группа сразу идёт через выход, где её ждут |
| `say <текст>` | строка в чат всем игрокам |
| `quit`, `exit`, `stop`, Ctrl+C, закрытие окна | сохранить мир и выйти |

Команды `coop_players`, `coop_kick`, `coop_restore`, `coop_time` работают и у обычного хоста в консоли игры.

Если стандартный ввод процесса при старте это канал или файл, он читается рядом с окном. Этим лаунчер просит сервер завершиться: пишет `quit`.

## Лаунчер

Кнопка «Сервер на этом ПК» в боковой панели. Карточка: выбор мира, порт, запуск. Когда сервер работает: порт, «Войти в игру», «Сохранить и остановить», список команд.

- Exe запускается под именем `bin\RayLinkServer.exe` (жёсткая ссылка). Mk наследуют это имя, поэтому «игра запущена» и «сервер запущен» лаунчер различает по имени процесса.
- Папка сервера: `%APPDATA%\RayLink\server\<игра>`, отдельно от профилей игроков.
- Сервер переживает закрытие лаунчера. Тогда лаунчер видит его по процессу, а остановить можно только из окна сервера.
- «Играть» при работающем сервере этого стенда запускает игру с `-coop_connect 127.0.0.1:<порт>`.
