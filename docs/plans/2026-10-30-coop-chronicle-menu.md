# Окно «Кооператив»: вариант D «Хроника + карта»

Решение владельца 2026-10-30: «создаю игру, в ней ведутся сохранения; выбрал игру и играю; рядом кнопка, которая показывает все
сохранения, чтобы откатиться; карта, чтобы увидеть историю похождений; желательно с анимациями».
Прототип, он же эталон вида и анимаций: `temp/coop-menu-mock` (`d.js`, `d.css`, `style.css`), снимки `v_d.png`, `v_d_open.png`.
Запуск: конфигурация `coop-menu-mock` в `D:\Projects\ForEverything\.claude\launch.json`, http://localhost:5190/index.html?v=d

## Цель и границы

Главный экран окна в покое: игры слева, арт локации на весь экран, название, «ИГРАТЬ», окошко карты. Окошко раскрывается в карту с
маршрутом сохранений, справа хроника с откатом. Внизу строка статуса и подключение к другу по адресу.

Не делаем сейчас: закрепление сохранений (задел в именах есть), снимки экрана в сохранениях, Steam-лобби внутри игры (лобби живёт
в лаунчере, игра запускается с `-coop_host` / `-coop_connect`).

## Контракт движок ↔ Lua

- `coop.autosave.set_game(id)`: пространство имён кольца. `id` = id игры (`[0-9a-z-]`, до 32 символов); пустая строка = старое поведение.
- Имя слота: `coop_auto_<id>_<N>`; без игры `coop_auto_<N>`. Временные `coop_auto_tmp`, `coop_auto_bak` общие, как сейчас.
  Кольцо считает только слоты своей игры. Старые `coop_auto_<N>` не трогаются и не вращаются.
- Решение владельца 2026-10-30: движок даёт общие функции и методы для UI, какие понадобятся, а меню целиком описано скриптами.
  Слова про меню, игру и стиль в движок не попадают. Чего не хватает в Lua — добавляем общим методом, а не обходим.
- Новые методы: `RegisterFont(name, texture_base[, shader])`, `GetFontByName(name)`, `CUIWindow:SetClipChildren(bool)`. На старом exe
  их может не быть: скрипты проверяют наличие и упрощают показ, не падают. Шрифты объявляет скрипт темы, атласы лежат в `gamedata\`.

## Тема: вид по сборкам

Логика окна общая (`gamedata\`). Всё, что вопрос вкуса (цвета по ролям, шрифты, правила артов, тонировка карты, размеры, длительности),
лежит в теме: `coop_menu_theme.script` в `gamedata\` для чистой Anomaly, тот же путь в `gamedata_gamma\` для G.A.M.M.A. (слой
`Anomaly Coop - GAMMA` выше Core, лаунчер кладёт его только для GAMMA). Нет поля в теме — значение по умолчанию, не вылет.
Новая сборка = новая тема в своём слое, код не меняется. Так же будет устроено главное меню.

## Данные (Lua)

- Игра: карточка `<id>.cgame`. Новое поле `title` (название от игрока); пусто = «Игра от <created>». Поле `name` остаётся именем персонажа.
- Каждое сохранение несёт в блоке `.scoc` (`m_data.coop_game`) поле `at = { level, game_time, real_time, players = {...} }`.
  `game_of_save(stem)` его отдаёт: читается один раз на имя | время | размер, без `CSavedGameWrapper`.
- Сохранения игры: все `*.scop` папки, чей блок несёт этот `id`. Разбор растянут на кадры, окно не подвисает.
- Старые сохранения без `at`: `coop_saves.details()` по одному, вне сессии, лениво.
- Координаты: `game_maps_single.ltx` (`[global_map] bound_rect`, `global_rect` уровней). Арт: `intro\intro_<level>_N`, рабочая область
  примерно x 4–96 %, y 7–71 %. Нашивки `ui_mm_faction_*`. Название локации: перевод `level`.

## Поведение

- ИГРАТЬ: хост после загрузки последнего сохранения игры (`host_when_ready` + загрузка).
- Откатиться сюда: вне сессии то же, но выбранное сохранение; в сессии у хоста — `coop_saves.restore(name)` с подтверждением.
- Новая игра: окно с полем названия, затем стоковый экран новой игры.
- В сессии: слева вместо игр игроки с пингом, внизу адрес и «Отключиться»; хроника и откат те же (только хост).
- Клиент: подключение из строки внизу; вкладка Steam убрана, вместо неё подпись про лаунчер.

## Анимации (покадрово из `Update`, отключаются опцией «меньше движения» если она есть)

Дрейф арта (прямоугольник текстуры), смена игры с перекрытием (альфа двух слоёв), раскрытие окна карты (размер окна + прямоугольник
текстуры, 0,45 с, закрытие 0,35 с, кривая cubic-bezier(.62,.02,.18,1): решение владельца 2026-10-30 после игры, всё открытие укладывается в полсекунды), камера по карте, маршрут точками по очереди, остановки с задержкой, строки хроники
с шагом 28 мс, раскрытие выбранной строки. Время через `time_continual`, а не кадры.

# Главное меню «Привал» (решение владельца 2026-10-30)

Эталон вида и движения: `temp/coop-menu-mock/menu.html` (`menu.js`, `menu.css`), концепт 1, снимок `mm1.png`. Порядок тот же: нужные
общие методы в движок, само меню скриптами, вид по сборкам в теме (логотип, акцент, арты пунктов, искры, длительности).

- Класс `ui_main_menu.main_menu` и его обработчики остаются: на них опираются моды GAMMA (`main_menu_on_init`, обёртки `OnButton_*`).
  Стоковые фон и `CUIMMShniaga` скрываются, новый вид строится поверх из `main_menu_on_init`. Тема может выключить вид: тогда стоковое меню.
- Пункты берутся из тех же списков XML (`menu_main`, `menu_main_last_save`, `menu_main_single`, `menu_main_single_dead`), поэтому кнопки модов
  (`btn_mcm`, `btn_coop` и другие) появляются сами. Если для списка и нажатия нужен общий метод `CUIMMShniaga` (имена кнопок, нажать по имени) — добавить в движок.
- «Продолжить» несёт название игры, место и дату (данные `coop_games`); нет сохранений — пункта нет, как в стоке.
- Анимации: появление логотипа и пунктов по очереди, смена арта под курсором (две картинки с перекрытием), дрейф арта, рамка-уголки
  плывёт к пункту и растёт под подпись, редкие искры (пул статиков), клавиатура и мышь. Переход в окно Хроники без вспышки: тот же арт.
- В игре по Esc то же меню со своим списком и артом текущей локации.
- Переиспользовать `coop_menu_kit.script` (анимации, раскладка) и `coop_menu_theme`. Логотип GAMMA: `GAMMAMainMenuLogo.dds`, для Anomaly — свой из темы.

Как сделано (`gamedata\scripts\coop_main_menu.script`):
- Подключение: `modxml_coop_menu.main_menu_init` вызывает `coop_main_menu.attach(menu)` под `pcall`. Вид лежит в `menu.coop_view` и строится заново с каждым окном меню, поэтому `MAIN_MENU_RELOADED` отдельно не нужен: движок сам создаёт новое окно, и `main_menu_on_init` срабатывает снова.
- Виджет: `SetSilent(true)`, список `GetButtonCount/Name/Caption`, нажатие `PressButton`. Нет любого из методов, тема выключила вид, сбой при сборке или в кадре: вид скрыт, `SetSilent(false)`, в логе одна строка `[coop-main-menu] !`.
- Общий код: `coop_ui_kit.script` (виджеты, шрифты, `ui:hero` с двумя слоями и дрейфом) и `coop_menu_kit.script` (раскладка `layout`, якоря, твины, кривые, `cover`). Окно Хроники и меню строятся одним набором вызовов.
- Первый кадр холодного меню занимает секунды. Кадр длиннее `main_menu.anim.stall` сдвигает начало появления, иначе игрок его не увидит. Арты всех пунктов загружаются в этом же кадре статиками 1×1 с нулевой альфой.
- Указатель, который уже стоял на строке при открытии, ничего не выбирает, пока не сдвинется.
- Логотип Anomaly: отдельного файла в игре нет, он впечатан в непрозрачный `ui\ui_actor_main_menu`. Тема берёт этот кусок (`rect`) и растворяет края (`feather`). Чистый логотип потребовал бы нового DDS с альфой.
- Арт: `arts` темы по имени кнопки; «Продолжить» показывает локацию сохранения, в уровне все пункты показывают текущую локацию. Переход в Хронику начинается с того же арта, обратно меню берёт арт окна и плавно идёт к своему.

## Уточнения при реализации

- Шаблоны окна: `configs\ui\ui_coop_chronicle.xml` (новое имя намеренно: старые `ui_coop_menu.xml` и `ui_coop_menu_16.xml` удалены, а уцелевший
  в чьей-то папке `_16` мог бы подхватиться движком и уронить окно на `XML node not found`). `_16` этому окну не нужен.
- Модули: `coop_games` (данные), `coop_menu_kit` (чистые помощники, без вида), `coop_menu_theme_base` (значения по умолчанию и сборка темы, никогда
  не подменяется), `coop_menu_theme` (тема сборки, тот же путь в `gamedata_gamma\`), `coop_menu` (логика окна и сессии).
- Реальные расстояния на карте больше экрана: маршрут Бар - Болота при масштабе прототипа занимает около 1060 px. Поэтому карта отъезжает под маршрут
  (`map.fit`, `map.least`), юг карты растворяется в фон (`map.fade_h`), а зеркальные копии по бокам лежат только под тенью: камера держит светлую часть
  экрана на самой карте (`map.lit`). Зеркало в открытую выглядит как клякса Роршаха (vault: W4 menu, failed). Маршрут длиннее свободной части показывает свой новый конец.
- Статик под файл текстуры делается из `tpl_image` (без `<texture>`): `InitTexture` файла оставляет прямоугольник, который у статика уже был.
- Текст в движке рисуется после всех статиков. Диалог поверх окна держится на `SetClipChildren(true)`: окно с обрезкой сбрасывает очередь текста до своих детей.
- В сессии на экране только запущенная игра: откат грузит сохранение игры с экрана, и это должна быть игра сессии. Мир без карточки показывает окно без игры.
- Каждый выбор игры называет кольцо автосейвов (`coop_game_settings.autosave_game`): Играть, откат, новая игра (пусто до записи), открыть мир напарникам (`ensure_record`).
- Шрифты: `RegisterFont("menu_title", "ui\\ui_font_menu_title")` и так далее, ярус выбирает движок по высоте экрана. На 4:3 текст выходит примерно на треть крупнее блоков: см. чек-лист.
- Хроника: между строками тихая строка `tl_gap`. Смена дня показывает дату сохранения (по его штампу, не сегодняшнюю), разрыв больше `gap_minutes` на одном дне показывает «35 мин без сохранений». Верхняя строка прокрученного списка называет свой день. Заголовок хранит дату самого нового сохранения.
- `CUIStatic:GetTextureSize()` при заданном `SetTextureRect` возвращает этот прямоугольник, а не файл. Поэтому `ui:load_image` сначала обнуляет прямоугольник: без этого каждая новая картинка увеличивалась внутри предыдущей.
