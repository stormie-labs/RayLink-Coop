# Ф1. MO2 и GAMMA — план реализации

> **Для исполнителей-агентов:** обязательный навык — superpowers:subagent-driven-development (рекомендуется) или
> superpowers:executing-plans; задачи выполняются по шагам. Шаги размечены чекбоксами (`- [ ]`) для отслеживания.

**Цель:**
- стенд разработки из профиля GAMMA (две копии игры);
- наш мод упакован как три мода MO2;
- первый вход хоста и клиента на GAMMA.

**Архитектура:** стенд не использует USVFS. Скрипт раскладывает файлы включённых модов профиля в отдельную папку
жёсткими ссылками в порядке приоритета MO2, сверху кладёт наши моды. Дальше работают те же `deploy` и `launch`, что и
для стока.

**Стек:** Python 3.14 (стандартная библиотека), PowerShell 5.1, FOMOD XML.

**Спецификация:** `docs/MO2_GAMMA.md`, `TZ.md` (Ф1).

## Глобальные ограничения

- MO2 GAMMA: `E:\GAMMA` (portable), игра `E:\Anomaly`, моды `E:\GAMMA\mods`, профиль `E:\GAMMA\profiles\G.A.M.M.A`.
- В `modlist.txt` первая строка — наивысший приоритет. `+` включён, `-` выключен; `*_separator` — не мод.
- Файлы мода отображаются в корень игры: `gamedata\…`, `bin\…`, `db\…` мода ложатся в те же пути стенда.
- Порядок слоёв стенда, снизу вверх:
  1. игра `E:\Anomaly` (её `gamedata` — это modded exes GAMMA);
  2. `Anomaly Coop - Engine`;
  3. моды профиля по приоритету;
  4. `E:\GAMMA\overwrite`;
  5. `Anomaly Coop - Core`;
  6. `Anomaly Coop - GAMMA`.
- Сравнение путей — без учёта регистра (Windows). `meta.ini` в корне мода в стенд не попадает.
- Только жёсткие ссылки (тот же том `E:`), никаких копий больших архивов. Чужие файлы в `E:\GAMMA` и `E:\Anomaly` не
  менять.
- Игру не запускать — запуск по слову владельца (задача 4).

## Что проверить отдельно

1. Два мода кладут один файл с разным регистром пути (`Scripts` и `scripts`): побеждает мод с большим приоритетом,
   в стенде один файл. Тест в задаче 1.
2. Мод с `bin\` (например, `Reshade Disabler`) перекрывает файлы `bin` игры. Тест в задаче 1.
3. Повторный запуск стенда после выключения мода в профиле: файл этого мода исчезает из стенда. Тест в задаче 1.
4. Пробелы и не-ASCII в именах модов (`G.A.M.M.A. YACS no quit`, русские буквы). Тест в задаче 1.
5. Стенд на другом томе, чем моды (жёсткая ссылка невозможна): понятная ошибка, а не тихое копирование 30 ГБ.
   Тест в задаче 1.

### Задача 1: `tools/mo2_stand.py` — материализация профиля

**Файлы:**
- Создать: `tools/mo2_stand.py`, `tests/tools/test_mo2_stand.py`

**Интерфейсы:**
- Даёт CLI: `python tools/mo2_stand.py --mo2 E:\GAMMA --profile G.A.M.M.A --game E:\Anomaly --out E:\AnomalyCoopGamma
  [--layer-bottom DIR] [--layer-top DIR ...] [--report temp/mo2_stand_report.txt]`
- Даёт функции:
  - `read_modlist(path) -> list[str]` — включённые моды, от наименьшего приоритета к наибольшему, без разделителей;
  - `build_layers(game, bottom, mods_dir, mods, overwrite, tops) -> list[Path]`;
  - `materialize(layers, out) -> Report`, где `Report = {files: int, conflicts: dict[str, list[str]], removed: int,
    seconds: float}`.

- [ ] **Шаг 1: тесты** на фальшивом дереве в `temp/`:
  - `test_modlist_order`: строки `+A`, `-B`, `+X_separator`, `+C` → `["C", "A"]`;
  - `test_case_insensitive_override`: мод с большим приоритетом с `gamedata/Scripts/x.script` перекрывает
    `gamedata/scripts/x.script` → в стенде одна ссылка на файл победителя;
  - `test_bin_layer`: `bin/dxgi.dll` мода перекрывает `bin/dxgi.dll` игры;
  - `test_stale_removed`: второй прогон без мода → его файл удалён, `removed == 1`;
  - `test_unicode_names`: мод `Мод с пробелом` раскладывается;
  - `test_meta_ini_skipped`;
  - `test_cross_volume_error`: `os.link` бросает `OSError` (подмена) → `SystemExit` с сообщением `hardlink impossible`.
- [ ] **Шаг 2:** `python -m pytest tests/tools/test_mo2_stand.py -q` → FAIL.
- [ ] **Шаг 3:** реализовать.
  - Стенд пересобирается инкрементально: ссылка с тем же источником не трогается, лишние файлы удаляются.
  - Отчёт: число файлов, топ-20 конфликтов (путь → моды по порядку), удалено, время.
- [ ] **Шаг 4:** тесты → PASS.
- [ ] **Шаг 5:** боевой прогон на `E:\GAMMA`, профиль `G.A.M.M.A` → `E:\AnomalyCoopGamma`. В отчёте около 600
