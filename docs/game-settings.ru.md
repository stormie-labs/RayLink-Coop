# Настройки кооп-игры RayLink

[English](game-settings.md)

Что делает каждая настройка на экране создания кооп-игры. Их выбирает хост, и действуют они на всю группу: у клиентов эти пункты заблокированы.

**Где:** главное меню → Кооператив → Новая игра → «Настройки игры».

- **при создании** — выбирается только при создании игры, потом не меняется;
- **между сессиями** — хост может поменять у существующей игры, пока никто не играет.

Жирным в столбце «Значения» отмечено значение по умолчанию. Свои личные опции (графика, звук, управление) каждый игрок настраивает у себя.

## Смерть и помощь

| Пункт | Что делает | Значения | Когда |
|---|---|---|---|
| Режим смерти | **Привалы** — после смерти игрок возрождается на своём привале, мир не откатывается. **Хардкор** — смерть окончательна: персонаж выбывает, игрок заходит новым персонажем. **Откат к сохранению** — никто ничего не теряет; через 5 секунд хост загружает последнее сохранение этой игры, и все перезаходят. | **Привалы** / Хардкор / Откат к сохранению | при создании |
| Что теряется при смерти | **Мешочек у тела** — часть рюкзака остаётся в мешочке у тела, за ним можно вернуться. **Весь рюкзак в тайник** — всё, кроме надетого и квестового, уходит в тайник у тела с меткой на КПК. **Пропадает** — часть рюкзака исчезает насовсем. **Ничего не выпадает** — рюкзак цел. Квестовые предметы не теряются никогда. | **Мешочек у тела** / Весь рюкзак в тайник / Пропадает / Ничего не выпадает | между сессиями |
| Сколько выпадает | Множитель доли рюкзака, которая выпадает или пропадает: 200 % забирает вдвое больше обычного. Виден только для «Мешочек у тела» и «Пропадает». | 50 / **100** / 150 / 200 % | между сессиями |
| Задержка возрождения | Сколько ждать после смерти до возрождения. Всё это время игрок смотрит глазами живого союзника и может писать в чат. | 0 / 15 / **30** / 60 / 120 / 300 с | между сессиями |
| Контузия после смерти | Сколько минут после возрождения длятся размытие, слабость и пониженная выносливость. | 0 / 5 / **10** / 20 / 30 / 60 мин | между сессиями |
| Потеря денег при смерти | Какой процент наличных теряется при смерти. | 0 / 5 / **10** / 20 / 30 / 50 % | между сессиями |
| Износ снаряжения при смерти | Насколько изнашиваются оружие в слотах, броня и шлем за каждую смерть. | 0 / 5 / **10** / 20 / 30 / 50 % | между сессиями |
| Потеря ранга при смерти | Какой процент ранга теряется при смерти. | **0** / 5 / 10 / 20 % | между сессиями |
| Новый хардкор-персонаж получает набор | Получает ли новый персонаж стартовый набор вещей, когда прежний погиб в хардкоре. Виден только в режиме «Хардкор». | **выкл** / вкл | между сессиями |
| Время до гибели без помощи | Сколько раненый лежит и истекает кровью, прежде чем умереть. За это время напарник может поднять его аптечкой. | 30 / **60** / 90 / 120 / 180 / 300 с | между сессиями |
| Здоровье после поднятия | С каким здоровьем встаёт поднятый напарником игрок. | 10 / 20 / **30** / 50 / 75 / 100 % | между сессиями |
| Привалы для всей группы | Вкл — каждый видит привалы всех игроков группы. Выкл — только свой. | **вкл** / выкл | между сессиями |
| Сталкеры добивают упавшего игрока | Вкл — враг продолжает стрелять по раненому игроку на земле. Выкл — оставляет его и переключается на других. | **выкл** / вкл | между сессиями |

## Группа и экономика

| Пункт | Что делает | Значения | Когда |
|---|---|---|---|
| Огонь по своим | Вкл — пули и взрывы ранят других игроков группы. | **вкл** / выкл | между сессиями |
| Награды за задания | Кому достаётся награда: только тому, кто сдал задание; деньги поровну тем, кто сейчас в игре; поровну всем, кто играл; или полная награда каждому, кто играл. | **Тому, кто сдал** / Деньги поровну тем, кто в игре / Всем, кто играл: делить поровну / Всем, кто играл: полная награда | между сессиями |
| Новых персонажей не больше | Сколько новых персонажей можно создать в этом мире. | 1 / 2 / 4 / **8** / 16 / 32 / 64 | между сессиями |
| Раздельные карты | Игроки могут одновременно быть на разных локациях: хост на Кордоне, друг на Свалке. Выкл — группа переходит между локациями вместе. Нужна новая игра и больше свободной памяти на ПК хоста. | **выкл** / вкл | между сессиями, со следующей загрузки |
| Сюжетные карты — вместе | При раздельных картах важные сюжетные переходы группа всё равно проходит вместе. Виден, только если включены раздельные карты. | **вкл** / выкл | между сессиями, со следующей загрузки |
| Новые игроки появляются | Где появляется новый персонаж, который впервые зашёл в игру. | **На базе группировки** / Рядом с хостом | между сессиями |
| Перемещение всей группой | Быстрое перемещение (по карте КПК, через рюкзак, с проводником) работает только когда вся группа стоит в радиусе сбора, иначе оно отклоняется с подсказкой. Все, кто стоял рядом, переносятся вместе с игроком. Выкл — каждый перемещается один. При раздельных картах каждый перемещается один всегда. | **вкл** / выкл | между сессиями |
| Радиус сбора группы | В каком радиусе от перемещающегося должна стоять вся группа для общего быстрого перемещения. | 10 / **20** / 30 / 50 / 100 м | между сессиями |
| Путь занимает игровое время | Вкл — общее перемещение группой сдвигает игровое время, как в одиночной игре. Перемещение в одиночку общее время не сдвигает. | **вкл** / выкл | между сессиями |
| Телепорт берёт игроков в радиусе | Когда сюжетный телепорт переносит игрока, игроки в этом радиусе от него переносятся в ту же точку. 0 — только он сам. | 0 / 25 / **50** / 100 / 200 м | между сессиями |
| Сон | Кто разрешает игроку пропустить время предметом ожидания (например, «Подождать» в GAMMA). **Голосование** — согласиться должны все остальные игроки; кто не ответил, тот против. **Безопасно или голосование** — игрок в укрытии или у палатки соглашается сам, остальные голосуют. **Все рядом** — можно, если все стоят в радиусе ниже. **Решает хост** — время пропускает только хост, клиентам отказ (на выделенном сервере вместо этого голосование). Обычный сон на кровати этой настройкой не управляется: в коопе он общий, время проходит, когда отдыхают все. Когда игрок ложится (кровать, спальник, обморок), каждому другому бодрствующему игроку приходит окно «<ник> ложится спать на N ч. Лечь тоже?» — **Лечь тоже** укладывает его на те же часы с обычными проверками (кровотечение, радиация, место отдыха по решению хоста; при отказе окно показывает причину), **Не сейчас** (или Esc) закрывает окно. В бою или при открытом меню приходит только подсказка, а окно открывается, когда игрок освободится. | **Голосование** / Безопасно или голосование / Все рядом / Решает хост | между сессиями |
| Сон: все в радиусе | Для правила «Все рядом»: в каком радиусе от ожидающего должны стоять все игроки. | 3 / **6** / 10 / 20 / 30 м | между сессиями |
| Время на голосование | Сколько ждать ответов на голосование за пропуск времени. | 15 / **30** / 60 / 120 с | между сессиями |
| Самый долгий пропуск времени | На сколько часов можно пропустить время за один раз: ожиданием или перемещением. | 12 / 24 / **48** / 72 / 168 ч | между сессиями |
| Передача денег между игроками | Можно ли передавать деньги друг другу. | **вкл** / выкл | между сессиями |
| Самая большая передача | Сколько денег можно передать за один раз. | 10 тыс. / 100 тыс. / **1 млн** / 10 млн / 100 млн | между сессиями |
| Передача предметов: в радиусе | Пункт «Передать &lt;игроку&gt;» в меню инвентаря появляется для игроков, которые стоят ближе этого расстояния. Деньги можно передавать на любом расстоянии. | 2 / **5** / 10 / 20 м | между сессиями |
| Чужая добыча | Вкл — тело охраняет живой сталкер, который убил этого NPC: подошёл ближе 25 м — угрожает. Тело открывается, когда убийца мёртв или ушёл. Тела, убитые игроками, мутантами или напарниками, свободны всегда. Выкл — любое тело можно обыскать сразу. | **вкл** / выкл | между сессиями |

## Мир

Население, аномалии, выбросы и пси-шторма. Пункты слева на экране новой игры (группировка, сюжет, Открытая Зона) — стоковые Anomaly.

| Пункт | Что делает | Значения | Когда |
|---|---|---|---|
| Группировка | Группировка мира: с неё начинает сюжет, и на её базе появляются новые игроки. | список группировок | при создании |
| Сюжетный режим | Включён ли основной сюжет. | **вкл** / выкл | при создании |
| Открытая Зона | Все переходы между локациями открыты с самого начала. | **выкл** / вкл | при создании |
| Население сталкеров | Сколько сталкеров в Зоне. Стартовое заселение делается один раз при создании, дальше это скорость пополнения. | 25 / **50** / 75 / 100 % | между сессиями |
| Население мутантов | То же для мутантов. | 25 / 50 / **75** / 100 % | между сессиями |
| Бои вне поля зрения | Сражаются ли отряды, когда рядом нет игроков: везде, только в смартах или нигде. | **Полный** / Только в смартах / Выкл | между сессиями |
| Радиус без спавна | Ближе этого расстояния к игроку отряды не появляются. | 0 / 25 / 50 / **75** / 100 м | между сессиями, со следующей загрузки |
| Динамические аномалии | Аномалии меняют места после выбросов. | **вкл** / выкл | между сессиями, со следующей загрузки |
| Динамические отношения | Отношения между группировками меняются со временем. | **выкл** / вкл | между сессиями |
| Вертолёты | Появляются ли вертолёты. | **выкл** / вкл | между сессиями |
| Выбросы: включены, частота, исход, предупреждение | Включены ли выбросы, как часто, что они делают с теми, кто не укрылся, и как о них предупреждают. | **вкл**; 12 / **24** ч / 2 / 4 дня; исход и предупреждение — стоковые варианты | между сессиями; частота — со следующего выброса |
| Пси-шторма: включены, частота, исход, предупреждение | То же для пси-штормов. | **вкл**; 12 / **24** ч / 2 / 4 дня; исход и предупреждение — стоковые варианты | между сессиями; частота — со следующего шторма |
| Количество аномалий, шанс артефактов, отключить новые аномалии | Настройки мода Dynamic Anomalies Overhaul. Видны, только если мод установлен; действуют на новых локациях. | как в моде | между сессиями |

## Сложность и экономика

Стоковые пресеты Anomaly: сложность боя и цены. Выбираются слева на экране новой игры.

| Пункт | Что делает | Значения | Когда |
|---|---|---|---|
| Сложность игры | Пресет урона, точности и выживаемости. | стоковые 3 уровня | при создании |
| Сложность экономики | Пресет цен, наград и находок. | стоковые 3 уровня | при создании |
| Множители сложности и экономики | Тонкая настройка стоковых множителей. Доступна только у уже созданной игры. | шаги как в стоке | между сессиями |

## Сохранения

Вручную в кооп-сессии не сохраняются: мир сохраняет хост автоматически. Откатиться можно через «Кооператив» → «Восстановить автосейв».

| Пункт | Что делает | Значения | Когда |
|---|---|---|---|
| Автосохранение раз в | Как часто хост сохраняет мир. Ещё он сохраняет после общего сна и в конце сессии. | 5 / **10** / 15 / 20 / 30 / 60 мин / выкл | между сессиями |
| Автосохранений хранить | Сколько последних автосохранений держать; старые удаляются. | 3 / 5 / **10** / 20 / 50 | между сессиями |

## Прочее

Все остальные опции игры и настройки модов (MCM) хост берёт со своей машины при создании игры, и клиенты получают их от него. Поменять их можно в главном меню, в «Опциях» и «Настройках модов», а затем у игры нажать «Взять текущие с этой машины».
