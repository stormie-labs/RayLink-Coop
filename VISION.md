# Anomaly Coop — видение (2026-10-21)

От кооператива на двоих — к живой Зоне, где у каждого свой сюжет, друзья по группировке идут по нему вместе,
а в мире встречаются чужие.

## 1. Картина
Ты заходишь на сервер своим сталкером. У тебя свой сюжет: свои задания, своя история с торговцами, свой путь к
центру Зоны. Друг из твоей же группировки зовёт в группу — и дальше вы идёте по общему сюжету: одни задания на
двоих, общая добыча, общие метки на карте. Вы переходите с Кордона на Свалку, со Свалки в Бар — и это переходы между
мирами-серверами. По дороге встречаете других игроков: своя группировка — можно торговать и помогать, Долг против
Свободы — может закончиться перестрелкой. Зона живёт и без вас: отряды ходят, торговцы обновляют товар, выброс
накрывает всех.

## 2. Опыт игрока
- **Один.** Свой сюжет (личный прогресс), мир общий: встречаешь других, но твоя история — твоя.
- **В группе.** Только с игроками своей группировки. Общий сюжет группы, общие задания и награды (по правилам
  группы), видишь союзников на радаре и в КПК, поднимаешь раненого напарника.
- **Встречи.** Чужие группы видны в мире; отношения — как у их группировок. Базы группировок — мирные зоны.
- **Переходы.** Локация = мир-сервер. Переход на соседнюю локацию — переезд на другой сервер вместе с персонажем,
  инвентарём и прогрессом. Группа переходит вместе (голосование, как сейчас в коопе).
- **Возвращение.** Вышел — персонаж остаётся в сохранённом мире и ждёт тебя там же.

## 3. Понятия
| Понятие | Что это |
|---|---|
| Игрок | человек с ключом (`coop_player.key`) и ником |
| Персонаж | его сталкер: инвентарь, деньги, ранг, репутация, личный сюжет; хранится на сервере |
| Группировка | Одиночки, Долг, Свобода, …; задаёт, с кем можно в группу и кто враг |
| Группа | 2–4 игрока одной группировки, общий сюжет и правила |
| Мир-сервер | процесс, который держит живой одну локацию |
| Центр | хранит персонажей, сюжеты, группы, экономику и офлайн-жизнь Зоны |
| Фаза | состояние мира, каким его видит конкретный игрок/группа по своему сюжету |

## 4. Сюжет в три слоя
1. **Личный.** Инфопорции, задания, сюжетные линии (DRX, основная), отношения с NPC — у каждого персонажа свои.
2. **Группа.** При вступлении группа получает общий сюжетный слой: задания взятые в группе — общие; прогресс
   засчитывается всем участникам; при выходе личный прогресс остаётся у каждого.
3. **Мир.** Смерти NPC, отряды, захват смартов (Warfare), выбросы, экономика торговцев — общие для всех.
**Фазирование** для событий, меняющих мир по сюжету: Выжигатель мозгов, Монолит, уникальные сюжетные NPC и места.
Эффект — на игрока/группу, а не на мир: у того, кто отключил Выжигатель, пси-излучения нет; у того, кто не отключил, —
есть; сюжетная сцена разыгрывается в фазе группы. Глобальный мир этими событиями не меняется.

## 5. Группы
- Создать / позвать / выйти; лидер; размер 2–4 (настройка сервера).
- Только одна группировка; смена группировки (как в Anomaly) выводит из группы.
- Общие: задания группы, метки и радар, чат группы, правила наград (поровну / сдавшему), дружественный огонь (вкл/выкл).
- Подъём раненого напарника, общий переход между локациями.

## 6. Игроки разных группировок
- Отношение игрок↔игрок = отношение их группировок (и личная репутация).
- Режимы сервера: PvP выключен / только враждебные группировки / свободный PvP.
- Мирные зоны: базы группировок (как зона мира в Ростке).
- Торговля между игроками — через атомарную сделку хоста (уже есть).

## 7. Миры-серверы и центр (архитектура по этапам)
- **Мир-сервер**: выделенный процесс без своего игрока (dedicated), держит одну локацию: NPC, физику, игроков.
- **Центр**: персонажи, сюжеты (слои 1–2), группы, экономика, **офлайн-ALife** всей Зоны (отряды между локациями,
  респаун), единая выдача id объектов, хранилище вместо сейва одного процесса, общее время.
- **Переход**: мир-сервер A отдаёт персонажа центру → центр отдаёт серверу B → клиент переподключается и грузит B.
- **ALife**: распределённое владение — объект принадлежит серверу своей локации, отряд/игрок при переходе передаётся;
  онлайн-симуляция — на мире-сервере, офлайн — в центре.

## 8. Техническая база, которая уже есть
Хост-авторитет, куклы NPC, вход с загрузкой мира хоста, персонаж игрока по ключу с хранением у хоста, уход из мира
отсутствующих, синхронизация сюжета/предметов/торговли/времени, спека функций синхронизации (`SYNC_SPEC.md`).

## 9. Что закладываем уже сейчас (чтобы не переделывать)
- В API синхронизации (`SYNC_SPEC.md` §6) — области `world` / `player` / `object` с выносимым хранилищем; плюс слой
  сюжета: чей он — игрока, группы или мира.
- Состояние игрока хранить отдельно от мира (персонаж, личные инфопорции/задания).
- Сущность «группа» в движке даже при одной группе в коопе.
- Сервер не завязан на «актор хоста = игрок» (путь к dedicated).

## 10. Этапы
| Этап | Что | Готово, когда |
|---|---|---|
| 1. Кооп | 2–4 игрока, хост играет, одна локация, общий сюжет | стабильная сессия часами: вход/выход, переходы, сейвы, бой, задания |
| 2. Выделенный сервер | хост без игрока, 8–16 мест, группы по группировке, личный сюжет + сюжет группы, фазирование основных событий | группы играют параллельно на одной локации, сюжеты не мешают друг другу |
| 3. Центр профилей | персонажи/сюжеты/группы/экономика в центре; группа может уйти в свой мир-сервер | персонаж переходит между серверами без потерь |
| 4. Миры-серверы | сервер на локацию, офлайн-ALife в центре, переходы между серверами, встречи групп | Зона из нескольких локаций живёт одним миром |

## 11. Риски и открытые вопросы
- Производительность хоста: ИИ вокруг многих игроков; нужен интерес-менеджмент трафика (слать каждому только то, что рядом).
- Сюжет Anomaly рассчитан на одного героя — фазирование нужно продумать по каждой сюжетной линии.
- Моды/GAMMA: одинаковый набор у всех на сервере (отпечаток модлиста уже есть).
- Хостинг выделенных серверов, NAT, Steam-лобби.
- Честность: сервер проверяет всё, но клиентский урон/перки — зона доверия; античит — отдельная тема.
- Лицензии: движок открытый; ассеты Anomaly и модов — у игроков свои, мы их не распространяем.
