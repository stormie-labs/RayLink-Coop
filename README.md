- **One world for the group.** The host runs the world; friends join it with their own characters, money and inventories. The story, tasks, stashes and the A-Life of the Zone are shared.
- **Separate maps.** If the host turns it on, players can be on different levels at the same time: the host on Cordon, a friend on Garbage. Important story transitions can still be made together.
- **Wounds, camps and rescue.** A downed player can be picked up by a teammate. Death sends you back to your camp, ends the character in hardcore, or rolls the group back to the last save — the host chooses.
- **Group life.** Fast travel as a group, a shared sleep, votes on skipping time, task rewards split the way the host set, money and items passed between players.
- **Vanilla Anomaly or G.A.M.M.A.** The launcher prepares the game folder from your own installs; the host and the group play on the same files.

## How to start

1. **Install [RayLink Launcher](https://github.com/stormie-labs/RayLink-Launcher/releases/latest/download/RayLinkSetup.exe)** and add your Anomaly 1.5.3 (and, for G.A.M.M.A., your Mod Organizer folder).
2. **Press Play.** The launcher downloads this co-op build and prepares a separate game folder.
3. **Host or join in the game:** Main menu → Co-op. Everyone in the group needs the same build.

Builds come in two channels, picked in the launcher's settings:

| Channel | For whom |
|---|---|
| **Stable** | everyone; the main build |
| **Dev** | testers; new features first, may break |
