# RayLink Co-op

Co-op for **S.T.A.L.K.E.R. Anomaly 1.5.3** and **G.A.M.M.A.** on the RayLink Engine. / Кооператив для **S.T.A.L.K.E.R. Anomaly 1.5.3** и **G.A.M.M.A.** на движке RayLink Engine.

**Discord:** https://discord.gg/QuYN4CtJTz

## Install / Установка

Install and update through **RayLink Launcher**: https://github.com/stormie-labs/RayLink-Launcher/releases/latest/download/RayLinkSetup.exe

Устанавливается и обновляется через **RayLink Launcher** (ссылка выше). Builds of this repository are in [Releases](https://github.com/stormie-labs/RayLink-Coop/releases): **Stable** and **Dev** channels.
